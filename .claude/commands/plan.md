# /plan (versión corta, basada en ECC)

Solo para funciones nuevas o cambios que tocan varios archivos. Para arreglos pequeños, no planifiques: hazlo.

1. Mira por encima el código afectado (solo lo necesario).
2. Responde en castellano, máximo ~15 líneas:
   - **Qué entiendo:** 1-2 frases.
   - **Pasos:** 3-6 pasos numerados, cada uno en una línea.
   - **Riesgos:** 1-3, solo si son reales.
   - **Tiempo aprox.:** corto / medio / largo.
3. Termina con: "¿Ok?" y NO escribas código hasta recibir confirmación.

Si la función es demasiado grande para un hackathon de 48h, dilo y propón una versión más pequeña.
